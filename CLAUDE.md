# Instructions for Coding Agents (Claude & Assistant Agents)

Before making any changes or starting new work on the **PKA Global** codebase, follow these mandatory instructions:

---

## 1. Primary Directives
1. **Read Core Context:** Read [AGENTS.md](file:///c:/Users/Arun/Documents/GitHub/pkassociates/AGENTS.md) and [HISTORY.md](file:///c:/Users/Arun/Documents/GitHub/pkassociates/HISTORY.md) before writing any code or making modifications.
2. **Brand Consistency:** Always use `PKA Global` as the active brand name.
3. **Outcome-Focused Messaging:** Ensure content leads with client outcomes (visibility, reduced compliance risk, sustainable growth) rather than service lists.
4. **Zero Unverifiable Claims:** Never invent fake reviews, client testimonials, software accreditations, physical office locations, or unverified job openings.

## 2. Mandatory Verification & Workflow

2. Run production build: `npm run build`
3. Log all completed changes, routes added, and verification results chronologically in [HISTORY.md](file:///c:/Users/Arun/Documents/GitHub/pkassociates/HISTORY.md).
